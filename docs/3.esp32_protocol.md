# ESP32 JSON 指令

当前项目中已经使用到的主要指令如下。

## 读取机械臂反馈

发送：

```json
{"T":121}
```

期望返回：

```json
{"T":121,"joints_rad":[0,0,0,0,0],"joints_torque":[0,0,0,0,0]}
```

## 机械臂关节运动

```json
{"T":123,"base":0,"shoulder":0,"elbow":0,"hand":0,"r":0,"spd":25,"acc":5}
```

说明：

```text
base / shoulder / elbow / hand / r 使用弧度
spd 和 acc 会在发送前转换为整数
```

## 夹爪打开

```json
{"T":130,"spd":100,"acc":10,"torque":1000}
```

## 夹爪闭合

```json
{"T":131,"spd":100,"acc":10,"torque":1000}
```

## 夹爪指定角度

```json
{"T":132,"angle":30,"spd":100,"acc":10,"torque":1000}
```

## 夹爪反馈

```json
{"T":133}
```

## 夹爪力矩控制

```json
{"T":134,"cmd":1}
```

`id_config.py` 中存在：

```python
TORQUE_CTRL = 210
```

但当前 `ArmActuator` 尚未实现机械臂本体力矩开关命令，字段格式也未确认。因此目前只实现了夹爪力矩控制。
