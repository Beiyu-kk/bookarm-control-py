# ESP32 JSON 指令

当前项目使用换行分隔的 JSON 和 ESP32 通信。`JsonSerialTransport` 会发送紧凑 JSON，并在末尾追加换行。

## 机械臂反馈

发送：

```json
{"T":121}
```

期望返回包含 5 个关节角和 5 个力矩。当前解析器支持多种字段名：

```json
{"T":121,"joints_rad":[0,0,0,0,0],"joints_torque":[0,0,0,0,0]}
```

也支持：

```text
angles_rad, joints_deg, angles_deg, joints, q
torques, tau
data.joints_rad, data.joints, data.q
```

## 机械臂力矩开关

开启力矩：

```json
{"T":122,"cmd":1}
```

关闭力矩：

```json
{"T":122,"cmd":0}
```

## 机械臂关节运动

```json
{"T":123,"base":0,"shoulder":0,"elbow":0,"hand":0,"r":0,"spd":25,"acc":5}
```

说明：

```text
base / shoulder / elbow / hand / r 使用弧度
spd 和 acc 会在发送前向下取整为整数
```

## 单关节弧度指令

`ArmActuator.build_move_single_joint_rad()` 当前生成：

```json
{"id":101,"joint":1,"angle":0}
```

该接口只负责构造指令；真实固件是否启用该命令，需要按 ESP32 端实现确认。

## 夹爪打开

```json
{"T":130,"spd":100,"acc":10,"torque":1000}
```

## 夹爪闭合

```json
{"T":131,"spd":100,"acc":10,"torque":1000}
```

## 夹爪指定角度

```json
{"T":132,"angle":30,"spd":100,"acc":10,"torque":1000}
```

`angle` 使用角度制。

## 夹爪反馈

发送：

```json
{"T":133}
```

`GripperActuator.read_feedback()` 默认等待返回：

```json
{"T":1331,"target":"gripper","pos":0}
```

只要返回里有 `target="gripper"` 或包含 `pos` 字段，当前解析器就会认为是夹爪反馈。

## 夹爪力矩控制

```json
{"T":134,"cmd":1}
```

`cmd=1` 表示开启，`cmd=0` 表示关闭。

## 夹爪持续夹紧

```json
{"T":138,"spd":100,"acc":10,"torque":1000,"hold":-200}
```

`BookArm.hold_gripper_closed()` 使用该指令，适合抓取后保持夹持。
