# BookArm API

## 基本约定

当前默认末端执行器 frame 是 `link5`。关节顺序来自 URDF，当前高层接口使用 5 个机械臂关节：

```text
joint1_base
joint2_shoulder
joint3_elbow
joint4_wrist
joint_pole
```

`BookArm` 内部统一使用弧度。示例脚本里如果用角度定义目标构型，会先调用 `np.deg2rad(...)`。

## 创建机器人模型

```python
from bookarm_control_py import BookArm

robot = BookArm()
```

常用属性：

```python
robot.urdf_path
robot.end_effector_link
robot.joint_names
robot.nq
robot.neutral_q
```

## 运动学

```python
pose = robot.fkine(q)
pose_dict = robot.fkine_dict(q)
result = robot.ikine(target_position, target_rotation=None, q0=None)
result = robot.ikine_best_effort(target_position, target_rotation, q0=None)
```

`fkine()` 返回 Pinocchio 的 `SE3` 对象。`fkine_dict()` 返回：

```python
{
    "position": ...,
    "rotation": ...,
    "transform": ...,
}
```

`ikine()` 成功时返回 `IKResult`。如果没有达到容差，`success=False`。

`ikine_best_effort()` 返回 `BestEffortIKResult`。即使 `success=False`，`q` 也会保存搜索过程中误差最小的构型，并额外提供：

```python
result.position_error_norm
result.rotation_error_rad
```

## 机械臂连接与控制

机械臂单独串口：

```python
robot = BookArm()
robot.connect_serial_arm(port="COM8")

try:
    robot.enable_torque()
    robot.move_joints_rad(q)
    robot.move_zero_pose()
    feedback = robot.read_arm_feedback()
finally:
    robot.close()
```

机械臂和夹爪共用同一个 ESP32 串口：

```python
robot = BookArm()
robot.connect_serial(port="COM8")
```

默认运动参数定义在 `bookarm.py`：

```python
DEFAULT_MOVE_SPEED = 25.0
DEFAULT_MOVE_ACCELERATION = 5.0
```

覆盖速度和加速度：

```python
robot.move_joints_rad(q, speed=10, acceleration=3)
```

反馈读取：

```python
raw = robot.read_raw_feedback()
feedback = robot.read_arm_feedback(input_unit="rad")
feedback.raw
feedback.q_rad
feedback.torque
```

如果固件返回 `joints_rad` 或 `joints_deg`，代码会按字段名自动判断单位；如果返回 `joints` 或 `q` 这种无单位字段，则使用 `input_unit`。

## 夹爪连接与控制

```python
robot = BookArm()
robot.connect_serial_gripper(port="COM8")

try:
    robot.open_gripper()
    robot.close_gripper()
    robot.set_gripper_angle(30)
    robot.set_gripper_torque(1)
    robot.hold_gripper_closed()
    feedback = robot.read_gripper_feedback()
finally:
    robot.close()
```

`hold_gripper_closed()` 使用固件持续夹紧指令 `T=138`，适合抓取后返回起始构型时保持夹持。

## 相机坐标变换

`bookarm_control_py.camera.geometry.RigidTransform` 表示：

```text
target_point = R @ source_point + translation
```

`RigidTransform.from_json(path)` 支持两种标定文件格式：

```json
{"xyz_m": [x, y, z], "rpy_deg": [roll, pitch, yaw]}
```

或：

```json
{"matrix": [[...], [...], [...], [...]]}
```

如果两种字段同时存在，当前代码优先使用 `xyz_m` 和 `rpy_deg`，方便手动更新相机外参。
