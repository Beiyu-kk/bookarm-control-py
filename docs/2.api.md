# BookArm API

## 基本约定

当前默认末端执行器 frame 是：

```python
link5
```

关节角在 `BookArm` 内部统一使用弧度。示例脚本中如果用角度定义目标构型，会先通过：

```python
np.deg2rad(...)
```

转换成弧度。

## 模型与运动学

```python
from bookarm_control_py import BookArm

robot = BookArm()
```

常用运动学方法：

```python
robot.fkine(q)
robot.fkine_dict(q)
robot.ikine(target_position, target_rotation=None, q0=None)
robot.move_to_pose(target_position, target_rotation=None, q0=None)
```

`fkine()` 返回 Pinocchio 的 `SE3` 对象。`fkine_dict()` 返回更容易打印和查看的字典：

```python
{
    "position": ...,
    "rotation": ...,
    "transform": ...,
}
```

## 机械臂连接与控制

```python
robot = BookArm()
robot.connect_serial_arm(port="COM8")

try:
    robot.move_joints_rad(q)
    robot.move_zero_pose()
    feedback = robot.read_arm_feedback()
finally:
    robot.close()
```

原始反馈可以通过：

```python
robot.read_raw_feedback()
```

读取并解析后的机械臂反馈通过：

```python
robot.read_arm_feedback()
```

返回 `ArmFeedback`：

```python
feedback.raw
feedback.q_rad
feedback.torque
```

默认运动参数定义在 `bookarm.py` 中：

```python
DEFAULT_MOVE_SPEED = 25.0
DEFAULT_MOVE_ACCELERATION = 5.0
```

所以可以直接调用：

```python
robot.move_joints_rad(q)
```

需要覆盖速度和加速度时再写：

```python
robot.move_joints_rad(q, speed=10, acceleration=3)
```

## 夹爪连接与控制

```python
robot = BookArm()
robot.connect_serial_gripper(port="COM8")

try:
    robot.open_gripper()
    robot.close_gripper()
    robot.set_gripper_angle(30)
    robot.set_gripper_torque(1)
    feedback = robot.read_gripper_feedback()
finally:
    robot.close()
```

如果机械臂和夹爪共用同一个 ESP32 串口，使用：

```python
robot = BookArm()
robot.connect_serial(port="COM8")
```

这样会让机械臂和夹爪共享同一个串口连接，避免同一个 COM 口被打开两次。
