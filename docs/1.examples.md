# 示例脚本

所有硬件示例都建议在项目根目录运行，并先确认串口号，例如 `COM8`。

## 0. 机械臂连接检查

```powershell
python example/0.check_arm_connection.py --port COM8
```

用途：连接机械臂 ESP32，测试五关节力矩开关指令，读取机械臂反馈，并打印原始 JSON、关节角和力矩。

常用参数：

```powershell
--skip-torque-test
--torque-test-delay 5.0
```

## 1. 零位运动与反馈检查

```powershell
python example/1.zero_and_read.py --port COM8
```

用途：读取当前机械臂反馈，发送零位运动命令，等待机械臂稳定后再次读取反馈，检查是否到达零位，并用最终关节角计算末端位姿。

常用参数：

```powershell
--settle-time 5.0
--tolerance-deg 3.0
--speed 25.0
--acc 5.0
--input-unit rad
--show-raw
```

## 2. 移动到指定关节构型

```powershell
python example/2.move_arm_to_q.py --port COM8
```

用途：把真实机械臂移动到脚本 `main()` 中的 `q_target_deg`。当前默认目标为：

```python
q_target_deg = np.array([0.0, -70.0, 75.0, 0.0, 0.0], dtype=float)
```

## 3. 正逆运动学测试

```powershell
python example/3.check_fk_ik.py --port COM8
```

用途：使用 `main()` 中直接给定的目标位置和目标姿态求 IK，控制真实机械臂运动到求解结果，再读取反馈并用 FK 复核误差。

当前默认目标：

```python
target_position = np.array([0.2, 0.0, 0.2], dtype=float)
target_rpy_deg = np.array([0.0, 0.0, 0.0], dtype=float)
```

## 4. best-effort IK 真机测试

```powershell
python example/4.check_ikine_best_effort.py --port COM8
```

用途：连接真实机械臂测试 `BookArm.ikine_best_effort`。脚本会先移动到 `START_Q_DEG`，读取到位后的反馈作为 IK 初始值，再求解目标位姿。

`ikine_best_effort` 即使没有达到容差，也会返回搜索过程中最接近目标的关节构型。脚本默认会移动到这个构型，并打印关节误差、位置误差和姿态误差。

常用参数：

```powershell
--speed 25 --acceleration 5 --arm-wait 5
--max-iterations 500 --tolerance 1e-4 --step-size 0.4
```

## 5. 夹爪功能测试

```powershell
python example/5.check_gripper.py --port COM8
```

用途：测试夹爪反馈、打开、闭合、指定角度、力矩开关和持续夹紧指令 `T=138`。脚本会先读取夹爪反馈，并根据 `pos`、状态字段或角度推断当前开合状态。

## 6. 盲抓测试

```powershell
python example/6.blind_grasp.py --port COM8
```

用途：执行固定位置盲抓流程：

```text
1. 打开夹爪
2. 机械臂运动到起始构型 [0, -70, 75, 0, 0] deg
3. 用 IK 计算目标位置 [0.3, 0, 0.1] m 的抓取构型
4. 机械臂运动到抓取位置
5. 闭合夹爪
6. 保持夹爪闭合，机械臂返回起始构型
7. 打开夹爪释放
```

## 固定目标位姿抓取

```powershell
python scripts/arm/goal_pose_grasp.py --port COM8
```

用途：移动到脚本 `main()` 中固定写好的目标位姿，执行抓取，等待 `--grasp-hold-wait` 秒后返回起始构型。目标位置单位为米，目标姿态用 rpy 角度数组表示。

常用参数：

```powershell
--speed 25 --return-speed 20
--grasp-hold-wait 3 --arm-wait 5 --gripper-wait 1
--no-close
```

## 手动示教与回放

```powershell
python scripts/arm/manual_teach.py --port COM8
```

用途：关闭机械臂力矩后手动拖动示教，记录轨迹到 `recordings/manual_teach_trajectory.json`，并支持回放。脚本启动后终端会打印可用按键。

## RealSense D435 测试

```powershell
python scripts/camera/check_realsense_d435.py
python scripts/camera/view_realsense_point_cloud.py
```

`check_realsense_d435.py` 用于 RGB-D 实时显示和保存单帧数据；`view_realsense_point_cloud.py` 用于实时显示彩色点云。

## 点云选点抓取

```powershell
python scripts/camera_arm/click_point_grasp.py
python scripts/camera_arm/click_point_grasp.py --port COM8 --execute
```

默认先干跑，不连接机械臂。确认相机点、基座点和 IK 结果后，再加 `--execute` 执行真实抓取。相机位置改变后，请先更新 [camera_to_base.json](../calibration/camera_to_base.json)。
