# 当前项目使用到的 ESP32 JSON 指令记录

## 机械臂相关

命令：{"T":121}
功能：读取机械臂五个关节的角度和力矩。
常见返回：{"T":121,"joints_rad":[0,0,0,0,0],"joints_torque":[0,0,0,0,0]}
说明：代码也兼容 angles_rad、joints_deg、angles_deg、joints、q、torques、tau 以及 data.* 包裹格式。

命令：{"T":122,"cmd":1} {"T":122,"cmd":0}
功能：打开或关闭五个机械臂关节的力矩。cmd=1 开启，cmd=0 关闭。

命令：{"T":123,"base":0,"shoulder":0,"elbow":0,"hand":0,"r":1.57,"spd":25,"acc":5}
功能：控制机械臂各关节运动到指定位置。
说明：base、shoulder、elbow、hand、r 使用弧度；spd 和 acc 发送前会向下取整。

命令：{"id":101,"joint":1,"angle":0}
功能：构造单关节弧度指令。
说明：当前 Python 侧可以构造该指令，真实固件是否启用需要按 ESP32 端实现确认。

## 夹爪相关

命令：{"T":130,"spd":100,"acc":10,"torque":1000}
功能：夹爪打开。

命令：{"T":131,"spd":100,"acc":10,"torque":1000}
功能：夹爪关闭。

命令：{"T":132,"angle":30,"spd":100,"acc":10,"torque":1000}
功能：控制夹爪角度。angle 使用角度制。

命令：{"T":133}
功能：读取夹爪反馈。
常见返回：{"T":1331,"target":"gripper","pos":0}

命令：{"T":134,"cmd":1}
功能：夹爪力矩控制。cmd=1 开启，cmd=0 关闭。

命令：{"T":138,"spd":100,"acc":10,"torque":1000,"hold":-200}
功能：夹爪持续夹紧，用于抓取后保持夹持。
